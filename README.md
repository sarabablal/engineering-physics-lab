## Engineering Physics & Solid Mechanics Portfolio :
Welcome to my engineering physics and solid mechanics portfolio. This repository integrates continuous symbolic derivation, discrete numerical methods, and interactive visualizations to analyze complex dynamic assemblies and multibody kinematic systems.
## Repository Structure :
**telescopic_robotic_arm_kinematics_engine/:** A mathematical physics simulation engine that combines SymPy algebraic differentiation with NumPy finite differences to map the trajectory, absolute velocity errors, and Coriolis acceleration of an expanding, rotating single-link manipulator.

**kenimatic_tracker/:** A computational tracking utility designed to process discrete positional datasets, filter structural signal noise, and reconstruct exact motion profiles over time.

**cheat_sheet/:** A centralized mathematical and algorithmic reference guide containing fundamental formula derivations, vector mechanics identities, and Python implementations for numerical discretization.
